# Seguridad

Para reportar una vulnerabilidad, usa el aviso privado de GitHub (*Security* > *Report a vulnerability*) del repositorio. No abras un issue público con detalles explotables.

Alcance: el análisis lee los archivos del workspace y no modifica el código del proyecto. Solo escribe lo que se pide explícitamente (`--output`, `--index-dir`). Se soporta la última versión publicada.
